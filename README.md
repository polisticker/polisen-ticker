# Polishändelser live

Inofficiell ticker, lista och länskarta över Polisens senaste händelser, hämtade direkt i webbläsaren från Polisens öppna API ([polisen.se/api/events](https://polisen.se/api/events)). Uppdateras var 60:e sekund.

Sidan är inte gjord av eller kopplad till Polisen.

Live: https://polisticker.github.io/polisen-ticker/
